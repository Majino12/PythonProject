从完整正文到可核对的报告

1. 准备完整正文

上传整本 TXT、DOCX、带文字层的 PDF，或粘贴全文。保留第一章到结尾，章节标题尽量独立成行。TXT 建议使用 UTF-8 编码；请求上限 {{ config.MAX_CONTENT_LENGTH // (1024 * 1024) }} MB。

扫描图片 PDF 不支持直接识别，请先转换为可复制的文字。网页提取受网站结构影响，可能只有当前页面；分析整本书建议使用完整文件。

2. 选择分析方式

  • 自动选择：有模型配置时使用模型，否则运行基础统计与摘录。
  • 模型深度分析：分段阅读全文，汇总并复核结论；需要服务器配置可用模型。
  • 本地基础统计：提供章节、字符统计和原文摘录，不推断人物关系、主题或高潮。

首页“本次使用的模型”显示阅读、汇总、复核配置。模型配置方法见项目 README。模型模式会将正文片段发送给所配置的模型服务；使用远程服务时请确认这是你愿意使用的服务。

3. 等待实际处理

提交后显示服务器阶段进度。长篇小说的耗时取决于长度、模型速度与可用资源；页面不会用计时器推算完成。临时断网后可以重新连接进度，在同一浏览器刷新首页也可恢复任务查询。

如果任务失败，页面会显示原因。部分片段失败时，报告会标记部分完成，并保留实际覆盖率。

4. 核对范围，再读结论

  1. 查看分析方式、输入字符数、片段数和覆盖率。
  2. 检查逐章列表的最后一章是否对应原书结尾。
  3. 点击人物、事件和主题下的原文依据，结合上下文判断。
  4. 查看模型记录、警告和未成功处理的片段。

5. 保存报告

导出 JSON 可保留结构化结果、模型记录和引用；导出 HTML 可离线阅读。使用“打印 / 保存 PDF”打开浏览器打印窗口，再选择保存为 PDF。

报告不提供未经评测的准确率数字。引用确实存在、输入被完整处理，都不等于模型对小说的理解完全正确。
