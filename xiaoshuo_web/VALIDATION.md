## 自动化验证

- 79 项 Python 测试、4 项浏览器状态 JavaScript 测试通过。
- 超过 30 万字符、21 章回归测试：逐块提交原文精确重组，包含第 15 章以后和最后一页事件。
- 101 章、多层汇总回归测试：每层输入有界，中间结论数量递减，全部章节保留详细片段记录。
- 原文引用必须逐字匹配原始偏移；不存在的引文与不获证据支持的结论被拒绝。
- 混合正确/错误摘要逐条过滤，不使所有有效结论一起丢失。
- 每批审核最多 6 条同类结论，保留相邻否定上下文；全书归纳遗漏结尾时仍保留末章最靠后的至多两条已验证事实。
- 模型返回结构无效的 JSON 时，提取、审核、归纳三阶段均使相应缓存失效；相同原文重提交可恢复，成功响应仍可复用。
- 真实后台状态、排队容量、失联重试、404、413、429、服务中断、私有存储、缓存损坏和并发处理有测试覆盖。
- DOCX 顺序、UTF-8/GB18030/UTF-16、扫描 PDF 明确拒绝，以及 320,020 字符 PDF 末页保留与限额边界通过。
- 基础/旧格式/空报告、205 章报告完整呈现、XSS 转义、逐条引用链接均通过渲染测试。

## 实际模型测试

测试文本为本仓库原创两章短篇 `tests/fixtures/river_lantern.txt`（386 字符），不是第三方整书。使用 Qwen3.5 4B 提取，Qwen3.5 9B 复核与汇总，调用本机 Ollama。

最终运行状态为 `complete`，2/2 片段进入已验证结果，以下五项检查全部通过：

- 两章均保留。
- 全部输入片段均完成处理。
- 输出引文与原文字符偏移逐字对应。
- 末章结局证据保留。
- 全书摘要保留“尚未原谅”的否定条件。

人工检查最终摘要：保留账册记载的修桥款用途反转、陈明承认隐瞒、档案去向与林秋留下但尚未原谅的结局。部分候选缺少直接证据或引用格式不合规，被过滤并记录警告；`complete` 表示处理流程完成，不代表所有候选都正确或所有内容都已准确概括。

最终复现耗时 43.97 秒，复用了前轮相同输入与模型配置的真实响应缓存，仅重新计算失败或变化的步骤；这不是首次推理耗时基准。实测曾出现模型摘要超出请求条数，以及压缩时遗漏末尾条件；当前通过有界候选逐条审核、保留原始片段记录和末章已验证事实处理，不将不合规结果强行标为成功。

可复现命令（会调用已配置模型；云端配置会产生服务方用量）：

```bash
python scripts/evaluate_pipeline.py --live --output data/live-check.json
```

以上测试不是大规模人工标注准确率评测，不能得出“准确率达到某百分比”或“所有小说都能正确理解”的结论。引用核验与第二次模型审核只能降低部分错误；讽刺、别名、不可靠叙述、跨章因果和语义遗漏仍需人工核对。
