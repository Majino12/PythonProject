## 自动化验证

- 102 项 Python 测试、6 项浏览器状态 JavaScript 测试通过。
- 超过 30 万字符、21 章回归测试：逐块提交原文精确重组，包含第 15 章以后和最后一页事件。
- 101 章、多层汇总回归测试：每层输入有界，中间结论数量递减，全部章节保留详细片段记录。
- 原文引用必须逐字匹配原始偏移；不存在的引文与不获证据支持的结论被拒绝。
- 混合正确/错误摘要逐条过滤，不使所有有效结论一起丢失。
- 每批审核最多 6 条同类结论；先仅凭完整句引文检查支持，再单独核对相邻否定上下文，两关结果取交集；全书归纳遗漏结尾时仍保留末章最靠后的至多两条已验证事实。
- 模型返回结构无效的 JSON 时，提取、审核、归纳三阶段均使相应缓存失效；相同原文重提交可恢复，成功响应仍可复用。
- 真实后台状态、排队容量、失联重试、404、413、429、服务中断、私有存储、缓存损坏和并发处理有测试覆盖。
- DOCX 顺序、UTF-8/GB18030/UTF-16、扫描 PDF 明确拒绝，以及 320,020 字符 PDF 末页保留与限额边界通过。
- 基础/旧格式/空报告、205 章报告完整呈现、XSS 转义、逐条引用链接均通过渲染测试。

## 实际模型测试

测试文本为本仓库原创两章短篇 `tests/fixtures/river_lantern.txt`（386 字符），不是第三方整书。实际调用本机 Ollama：Qwen3.5 9B 提取、汇总、核验普通结论及上下文，Qwen3.5 4B 单独核验人物描述的直接证据与归属；两种模型均关闭 thinking。

### 直接证据正反案例

固定四例分别是：错误引用收据支持卷款传言、把两位父亲的行为合为一人、正确的买救济粮概述、正确的陈明父亲隐瞒概述。测试直接调用生产的两关审核函数，每例独立，模型错误或调用失败都算失败。

- 两关都使用 9B 时，3/4 符合预期，仍漏放两位父亲混淆。
- 两关都使用 4B 时，3/4 符合预期，错误拒绝一个正确的上下文案例；其第一关四例均正确。
- 当前分工在这四例上为 3/4，耗时 36.598 秒，缓存命中 0 次。两个错误案例均被拒绝，但“陈明承认父亲隐瞒”的正确概述被 9B 上下文复核错当成与另一位父亲的事实矛盾；脚本如实返回失败，未标为全部通过。同一模型在复跑中的判断也有波动，当前组合仍存在误拒和人物指代错误。
- 曾让 4B 承担全部直接引文审核，完整短篇运行只得到 1/2 片段的模型覆盖，并漏放标题支持收据事实的错配引文。该轮明确标为 `partial`，未当作验收通过；默认配置已改为 9B 主流程、4B 仅核验人物。
- 曾试用 9B thinking，首条案例在 300.05 秒超时，没有获得判定，因此未选为默认，也不能据此比较准确率。

上述案例参与了提示和配置调整，属于回归验证，不是独立测试集或泛化准确率。对其他作品的效果仍未知。

### 全流程短篇

修复前的首次无缓存流程耗时 428.0 秒，2/2 片段均有核验结果、五项结构与引用检查均通过，但第二章压缩误用内部结论编号作为原文证据编号，明确标为 `partial` 并保留原始已核验事实。随后有缓存复跑 46.8 秒仍复现，未把复跑当成功。现已移除汇总输入中的内部结论编号，仅保留原文证据编号；审核阶段仍使用结论编号关联判定，相关回归测试通过。

仅修复编号后的流程耗时 198.33 秒，状态 `complete` 且五项检查通过，但人工发现全书摘要把“林秋找到木盒”改成“陈明找到木盒”，模型审核未拦住。该轮没有作为语义验收通过。随后强制逐字复制的 188.48 秒测试拒绝了第一章全部改写候选，第二章重复审核也返回了无效结构，仍如实标为 `partial`。

最终汇总协议改为只输出所选事实的整数编号，由程序取回该事实的完整原句与引用；不再要求模型抄写文本，也不接受新的断言。所选事实继承上游已有的两关审核，不重复推理未改动的事实；非法、重复和越界编号被过滤。此约束防止汇总阶段新增这类错误，但不能证明上游模型事实本身全部正确。

当前完整流程状态为 `complete`，2/2 片段进入有核对结论的结果。五项检查全部通过：两章保留、输入片段全部处理、引文与字符偏移逐字匹配、末章结局证据保留、全书摘要保留“尚未原谅”的否定条件。

耗时 58.8 秒，客户端调用 18 次，缓存命中 12 次。调用计数含缓存和失败，不等于实际 HTTP 请求次数；此前相同原文的提取响应可能复用，这不是首次冷启动耗时基准。

人工核对最终报告，未再发现“陈明找到木盒”或两位父亲互换；传言、救济粮用途、档案去向、留下但未原谅均有保留。仍有两处上游引用范围不足：主题提到“放灯”但所引句子只含留下与未原谅；事件描述用“明确表示尚未原谅所有人”，所引句子却是叙述，后一条对白仅针对陈明。两关模型审核仍漏放了这些措辞与引文范围差异。结局补入机制也会让放灯事实追加在“未原谅”之后，最终展示顺序不保证严格时序。这些问题未标为语义验收通过，也未手工改写实测输出掩盖。

早期版本即便这五项检查通过，人工复核仍发现了错配引文和人物归属错误。因此不能把结构检查或 `complete` 当作内容正确率。当前采用分离的引文/上下文审核、完整句证据和独立逐条引用；候选被拒绝时记录警告并省略，不编造成功结论。部分细节仍可能误拒、遗漏或误解。
