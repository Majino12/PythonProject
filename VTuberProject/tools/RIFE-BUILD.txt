字段协议（不变）
  输入 576×720，右侧/底部补零至 64 的倍数；5 个推理尺度 [16,8,4,2,1]。
  模型返回最终四通道 backward flow，mask logits 取 sigmoid；其 RGB 输出由两端
  原图 warp 后按该 mask 合成，无另一个 RGB residual。仅提取 flow + mask。
  16 条既有三角网格边，各实际推理 t=i/8（i=1..7），共 112 次；端点仍为原画。
  存储 144×180，位移各分量除以输入宽高：
    flow.bin：无头，小端 float16，[7,180,144,4]，dx0,dy0,dx1,dy1。
    mask.bin：无头，uint8，[7,180,144]，除以 255 得 endpoint0 权重。
  图像 y 轴向下；像素中心与双线性采样；每个文件记录大小及 SHA256。
  loader 只接受新的固定作者/模型/权重/代码身份和上述语义，旧 4.6 manifest 会被拒绝。

此次全量结果（误差范围 0–1；均为代理指标，不是艺术质量分数）
  已检查 16 边 × 7 时刻，另跑两个模型各自的反向输入/时间；全部有限，原稿 hash 未变。
  4.25 完整字段在内部区域重建网络 RGB 平均误差 0.000000268，验证 flow/mask 语义。
  反向 RGB 一致性均值 4.6 0.01232 → 4.25 0.01083；15/16 边改善。
  right→right-down 回退：均值 0.01200 → 0.01329。
  4.25 全局最差为 front→right-down t=.5，0.02663；旧全局最差 0.02427。
  相同 144×180 存储对较细 flow 的近似损失上升：原分辨率脸部 premulRGB 误差均值
  0.00285 → 0.00407，最差 0.00548 → 0.00803；alpha 均值 0.000406 → 0.000631。
  全部逐边 mean/median/p95/worst/time 见 validation/v0.19-rife-model.json 与 CSV。
  此误差是原 1122×1402 RGBA 在完整 flow 和压缩 flow 下的差异，不是与真实中间稿比较。

视觉验收与限制
  已逐边查看 16 个中点及 4 个最差指标相关样例（含 t=.875），使用实际压缩字段
  warp 原分辨率 RGBA。下→右下、左上→正面、正面→右下的双眉眼/发线重影减少；
  未见新的大变形，但细发线略软，部分嘴部仍有轻微重影。并非所有指标获胜。
  provenance.json 固定 manifest、compiler、依赖锁、报告和许可 hash。
  CPU 4 线程单次均值 4.6 NCNN 0.403s、4.25 PyTorch 0.254s，仅是本机不同后端实测，
  不能据此声称新模型架构更快；浏览器只采样字段，不受离线推理时间影响。
  相邻时刻插值、三角形内部边场组合仍是几何近似；并非直接三视图神经推理。
  中性原稿 fields 被表情共用，需要实际浏览器表情/视线/透明边缘回归。
  模型不产出可靠的语义分层或被遮挡区域补画；不能把这次更换说成完整自动建模。
