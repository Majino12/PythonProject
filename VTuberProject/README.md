# MoeMotion 0.8

把一张角色图变成保留原画细节的可动 2D 形象，或用参考配色的 3D 角色进行演示、动捕和录制。2D 内置原创立绘「月见 Luna」；3D 默认使用获得授权的精致 VRM 模板，也保留较轻量的程序化角色。不需要先学绑定或建模，不开摄像头也能体验。

**精致 3D 是独立制作的模板模型，不是 Luna 或上传图片的三维重建。** 图片用于参考配色，模板的服装、发型和几何细节不会自动变成原图中的设计。

## 启动

安装 Node.js 18 或更新版本，在项目目录运行：

```bash
npm start
```

打开 [MoeMotion 工作台](http://127.0.0.1:4173)。不要直接双击 `index.html`。

首次识别图片或启用摄像头时，需要联网加载 MediaPipe 运行文件和模型；首次切换 3D 时需要加载 Three.js，精致版还会加载 three-vrm 运行库和项目内附带的 VRM 文件。识别、动作跟踪、配色和模型渲染在本机进行。

## 怎么使用

1. **创建角色**：上传 PNG、JPG、WEBP，或点击“让 AI 帮我画角色”，填写描述和临时 OpenAI API Key。推荐人物居中、正脸、五官清楚的图片；透明 PNG 更适合叠加到其他画面。
2. **选择外观和动作**：2D 保留原画线条与阴影；3D 的精致版提供 VRM 骨骼动作、模型表情与头发物理，轻量版保留程序化外观。用“半身 / 全身”调整取景；自动演示提供安静待机、打招呼和说话动作，待机默认闭嘴，配合呼吸与眨眼。
3. **按需微调**：展开“3D 外观微调”，修改发色、服装色和眼睛色，也可恢复自动外观。**短发 / 齐肩发 / 长发切换只适用于轻量版**，精致版保留原模型发型。“动作微调”调整动作幅度，不满意可“恢复默认动作”。

想用真人动作时，点击“开启摄像头”并同意后才会请求浏览器权限。坐姿或摄像头位置变化后点击“重新校准”，自然正视约 3 秒；“关闭摄像头”会停止使用并回到演示。

3D 预览可拖动旋转、双击回正，也支持左右方向键和 Home / 回车 / 空格回正。素材体检中的建议可展开查看。

## 保存，下次继续

项目名称、当前角色图片和设置（包括取景、演示动作、精致 / 轻量模型选择与 3D 外观微调）会自动保存到**当前浏览器的 IndexedDB**，保留一个当前项目。重新打开页面会尝试恢复角色和设置，但动作来源仍为自动演示，不会自动开启摄像头。旧项目未保存模型类型时，默认选择精致版。

- “下载项目”获得 `.moemotion` 备份，之后可用“打开项目”恢复，也可换到其他设备继续。
- 自动保存不可用或失败时，按页面提示下载项目，不要依赖本机存档。
- 清理浏览器数据、使用其他浏览器或更换访问地址，可能无法找到原存档。重要角色请主动下载备份。
- 自动保存和项目备份**不包含 API 密钥、摄像头帧或录制视频**。录制和截图需要单独下载。
- `.moemotion` 备份保存图片和设置，不复制内置 VRM 文件；在另一设备恢复时仍需使用完整的 MoeMotion 项目。

## 展示和输出

- **截图**：下载当前角色画面的 PNG。选择“透明背景”只移除舞台背景；图片自身的白底等不会自动抠掉。
- **录制视频**：只录制角色画面，**不录音**。浏览器自动选择支持的 WebM / MP4 格式；透明视频的效果取决于编码格式和播放软件。
- **纯净预览**：在当前页面隐藏控制面板，按 Esc 或点击“退出预览”返回。可用直播软件的窗口采集功能采集这个页面；它不是虚拟摄像头，退出按钮等页面提示也可能被窗口采集到。
- **精致版下载 VRM**：输出应用当前配色的 `.vrm`，保留原模型的网格、骨骼、VRM 扩展和许可元数据。部分贴图会附加替换 PNG，原始二进制内容仍保留。导出使用原模型的原始姿态，不包含当前表情、摄像头动作或演示时间线；接收软件对 VRM 的支持程度会影响显示效果。
- **轻量版下载 GLB**：导出中立姿态的 `.glb` 场景，不是 VRM，不包含预录动作。实时跟踪仍由本页面驱动。

## 隐私和能力边界

摄像头画面只在浏览器内处理，不上传服务器，也不会自动保存。导入的本地图片不上传到 AI 服务。使用 AI 生成时，角色描述和临时 API Key 会经由本机服务发送给 OpenAI，可能产生 API 账户费用；密钥不写入项目文件或持久化存储。

2D 使用 WebGL 对原图像素做柔和形变，不再用平面色块覆盖五官，适合中小角度动作；未识别人脸或 WebGL 不可用时，保留未形变的原图。它不是完整 Live2D 网格绑定，单张图不能补出转头后原本看不见的内容。

精致 3D 使用内置的授权 VRM 模板，按图片或手动设置调整配色，利用模型已有的骨骼、表情与头发物理进行动作演示和跟踪；并非从单张图自动生成同款网格或服装。轻量 3D 按图片区域提取配色、参考脸部比例，使用程序化几何组装动漫角色，发型为有限的短发、齐肩发和长发方案。两种模式都不会精确还原图片中被遮挡的身体或背面。

当前**不支持导入用户自己的 VRM**，不生成或读取 Cubism `.moc3`，也不提供自动抠图或虚拟摄像头。光线、遮挡、侧脸角度和身体出镜范围都会影响跟踪效果。模型自身已有的形状、骨骼和表情数量也会限制可表现的动作。

## 内置素材与许可

2D 立绘由图像生成工具原创生成，文件为 `assets/demo-luna-v1.png`，生成提示词保留在 `assets/demo-luna.prompt.txt`。它与精致 3D 模板是两份独立素材。

精致版使用 pixiv Inc. 的 `VRM1_Constraint_Twist_Sample`（v1.0.1），项目内文件为 `assets/pixiv-vrm1-sample.vrm`。来源是 [pixiv/three-vrm 的固定提交](https://github.com/pixiv/three-vrm/blob/5a3242b66124386c32b085c6693d9059040e72e5/packages/three-vrm/examples/models/VRM1_Constraint_Twist_Sample.vrm)，另见 [官方样例说明](https://github.com/vrm-c/vrm-specification/blob/master/samples/VRM1_Constraint_Twist_Sample/README.md)。

该模型使用 **VRM Public License 1.0 及文件内许可设置**，不是 three-vrm 软件代码的 MIT 许可，也不是 MoeMotion 独占的原创模型。来源、文件校验值、许可设置和再分发注意事项记录在 `assets/THIRD_PARTY_NOTICES.txt`；模型使用和再分发应遵守其中记录的许可，不要删除出处或把原模型网格、贴图重新声明为 MIT / 公有领域。下载的改色 VRM 保留原模型许可信息，仍受原许可约束。

## 检查和版本

```bash
npm run check
npm test
```

v0.8 加入授权精致 VRM 模板、骨骼和表情驱动、头发物理及配色 VRM 下载；保留轻量 3D 和 GLB 输出，模型类型随项目保存。精致版不是图片重建，也不提供任意 VRM 导入。

v0.7 更新原创示例立绘、原图像素柔和形变和风格化 3D 外观；加入安静待机等演示动作、半身/全身取景、发型与配色微调。测试覆盖动作映射、外观提取、形变、项目数据验证和关键操作生命周期。

v0.6 精简重复入口，加入项目保存/备份、重新校准、截图和纯净预览，修复重复提交及录制冲突；这些功能在后续版本中继续保留。
