# MoeMotion

MoeMotion 是一个“单张立绘直接动起来”的本地优先 VTuber 原型。它不要求用户学习 Live2D 切图、参数和绑定流程：导入正脸角色图后，应用会自动定位眼睛与嘴部，再使用摄像头驱动眨眼、口型、摇头和轻微身体摆动。

## 当前版本（v0.2 Easy Mode）

- 导入 PNG、JPG、WEBP 角色图
- 基于 MediaPipe 的自动五官识别与摄像头面捕
- 眨眼、张嘴、头部倾斜和左右移动
- 无摄像头的自动演示模式
- 渐变、透明、绿幕三种背景
- 直接录制并导出 WebM 视频
- 所有图片和摄像头画面只在浏览器本机处理，不上传服务器
- 首次打开的一键引导与始终可见的三步进度
- 自动素材体检：分辨率、画面比例、五官识别结果
- 摄像头连接后的三秒自动校准与中立姿态修正
- 根据当前状态只推荐一个明确的下一步操作
- 自动记忆背景和动作灵敏度设置

## 启动

需要 Node.js 18 或更新版本：

```bash
npm start
```

然后打开 <http://127.0.0.1:4173>。

首次启用自动绑定或摄像头时，需要联网下载 MediaPipe 运行文件与人脸模型。下载完成后，角色图片与摄像头帧仍只在本机处理。

## 推荐素材

- 正面或接近正面的角色图
- 五官无遮挡、眼睛与嘴部清晰
- 竖版图片，角色居中
- PNG 透明背景可获得更好的录制效果

## 产品路线

1. **v0.1 单图动捕**：验证“零绑定”使用体验（已完成）
2. **v0.2 傻瓜模式**：一键向导、素材体检、自动校准和操作提示（当前版本）
3. **v0.3 自动分层**：头发、脸、眼睛、嘴、身体语义分割与缺失区域补全
4. **v0.4 AI 角色工坊**：文字或草图生成可绑定的角色立绘，并保持角色一致性
5. **v0.5 创作者输出**：OBS 虚拟摄像头、透明窗口、预设动作、表情快捷键
6. **v1.0 桌面应用**：离线模型、Windows/macOS 安装包、一键直播

## 技术说明

当前 MVP 使用浏览器 Canvas 进行轻量 2D 变形，动作捕捉基于 MediaPipe Face Landmarker。它不是 Cubism 模型，也不读取 `.moc3` 文件；目标是用更低的学习成本实现类似的实时表现力，并为后续自动分层与网格变形建立产品闭环。
