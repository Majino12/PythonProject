# MoeMotion

MoeMotion 是一个“单张立绘直接动起来”的本地优先 VTuber 原型。它不要求用户学习 Live2D 切图、参数、绑定或 3D 建模：导入或用 AI 生成角色图后，应用会自动绑定 2D，并可一键构建程序化 3D 卡通角色。摄像头是可选项，同一套动作会驱动 2D 和 3D。

## 当前版本（v0.4 Auto 3D）

- 导入 PNG、JPG、WEBP 角色图
- 基于 MediaPipe 的自动五官识别与摄像头面捕
- 眨眼、张嘴、头部倾斜和左右移动
- 无摄像头的自动演示模式
- 渐变、透明、绿幕三种背景
- 直接录制并导出 WebM 视频
- 导入的图片与摄像头画面只在浏览器本机处理，不上传服务器
- 首次打开的一键引导与始终可见的三步进度
- 自动素材体检：分辨率、画面比例、五官识别结果
- 摄像头连接后的三秒自动校准与中立姿态修正
- 根据当前状态只推荐一个明确的下一步操作
- 自动记忆背景和动作灵敏度设置
- 页面内填写角色描述和临时 OpenAI API Key，使用 GPT Image 2 自动生成角色立绘
- API Key 只经由本机服务转发一次，不写入源码、浏览器存储或日志
- MediaPipe Pose Landmarker 上半身跟踪：肩膀、双手、躯干倾斜和身体起伏
- 摄像头使用同意流程：先说明用途、范围和本地处理方式，再请求浏览器权限
- 一键切换 2D / 3D，不丢失当前图片、背景、动作来源和灵敏度
- 从导入或 AI 生成的立绘中自动提取肤色、发色、服装色、眼睛色与强调色
- 本地自动构建可旋转的程序化 Q 版 3D 角色，无需建模参数或确认弹窗
- 复用现有眨眼、口型、头部、躯干和双手跟踪数据实时驱动 3D
- 3D 预览支持拖动旋转、双击回正，支持渐变、透明和绿幕背景
- 一键下载单文件 `.glb` 模型；导出时自动使用中立姿态
- WebGL 或 Three.js 加载失败时自动回到 2D，不影响继续使用

使用 AI 生成功能时，角色描述和临时 API Key 会由本机服务发送到 OpenAI；导入的本地图片和摄像头帧不会随该请求上传。

## 启动

需要 Node.js 18 或更新版本：

```bash
npm start
```

然后打开 <http://127.0.0.1:4173>。

首次启用自动绑定或摄像头时，需要联网下载 MediaPipe 运行文件与模型；首次切换 3D 时需要加载固定版本的 Three.js。下载完成后，角色图片、3D 构建与摄像头帧仍只在本机处理。

## 最短使用方法

1. 直接点击预览顶部的 `3D`，示例角色会自动构建并开始动作。
2. 导入图片或使用页面里的 AI 生成功能，当前 2D / 3D 角色会自动更新。
3. 想使用真人动作时再点击“开启摄像头”；不打开也能使用自动演示。
4. 3D 模式下点击“下载 3D 模型”即可获得 `.glb` 文件。

导出的文件是标准 GLB 场景，不是 VRM，也不包含一段录制好的动作。实时动作由 MoeMotion 页面中的跟踪系统驱动。

## 推荐素材

- 正面或接近正面的角色图
- 五官无遮挡、眼睛与嘴部清晰
- 竖版图片，角色居中
- PNG 透明背景可获得更好的录制效果

## 产品路线

1. **v0.1 单图动捕**：验证“零绑定”使用体验（已完成）
2. **v0.2 傻瓜模式**：一键向导、素材体检、自动校准和操作提示（已完成）
3. **v0.3 AI 与肢体动捕**：页面生成角色、上半身姿态跟踪、摄像头同意（已完成）
4. **v0.4 自动 3D**：自动取色、程序化卡通角色、动作驱动与 GLB 导出（当前版本）
5. **v0.5 自动分层**：头发、脸、眼睛、嘴、身体语义分割与缺失区域补全
6. **v0.6 创作者输出**：OBS 虚拟摄像头、透明窗口、预设动作、表情快捷键
7. **v1.0 桌面应用**：离线模型、Windows/macOS 安装包、一键直播

## 技术说明

2D 使用浏览器 Canvas 进行轻量变形；3D 使用 Three.js 基础几何、材质和可动画节点层级自动组装角色；动作捕捉基于 MediaPipe Face Landmarker 与 Pose Landmarker。它不是 Cubism 模型，不读取 `.moc3`，当前也不声称生成 VRM；目标是用更低的学习成本实现相似的实时表现力，并为后续自动分层、网格变形和标准 VTuber 格式建立产品闭环。
