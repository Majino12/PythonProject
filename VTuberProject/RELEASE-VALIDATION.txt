VTuberProject 0.15.0 — release validation, 2026-10-28

Default: short-haired 2D avatar studio with nine prepared head poses, painted eye/mouth/brow expressions, independent gaze, 22 ARKit-named coefficients, optional camera tracking and local project/JSON/PNG/video export. No 3D changes in this release.

Changes in 0.15.0:
- Eight non-front poses now have five eye-opening and jaw-opening stages instead of three, using 16 selected new source portraits. Front retains its existing five stages.
- Eye and jaw motions advance through adjacent prepared artwork, including reversals from the currently displayed stage. This does not synthesize missing art by stretching or crossfading.
- The studio offers 30/60 fps targets, reports successful drawing measurements and uses the selected target for video capture. Requested fps is not guaranteed output or a count of distinct source drawings.

Validation:
- npm test: 589 passed, 0 failed, 0 skipped; npm run check passed.
- Focused lifecycle/timing tests: 48 passed (10 camera, 24 studio, 14 timing). Real camera hardware was not activated.
- Browser frame diagnostics: 718 native-pixel comparisons, 1060 assertions, 0 failures; includes all nine five-stage poses, upper-lip registration, extreme gaze clipping and exact inheritance of existing named states.
- All nine five-stage contact sheets and two new combined eye/mouth/gaze examples were visually inspected by the developer; no blocking compositing issue was found. This does not create a new user artwork-approval record.
- Right-down timing after the new artwork was enabled showed all five stages without skipped stages. Under the measured load: 60 fps target yielded about 55.93 fps; 30 fps target about 30.26 fps. Earlier front measurements were 60.0/30.0 fps. These measurements apply only to the tested session.
- A front VP9 recording contained 1694 video blocks over 28.224 seconds (about 59.98 fps), at 630x460. This front recording preceded activation of the new artwork and does not establish video performance for every pose or device.
- Release dependency audit: all 23 studio modules and 224 referenced asset paths exist; the server binds loopback and camera startup remains explicit.
