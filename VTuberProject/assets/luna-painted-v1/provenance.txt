MoeMotion — Luna painted 2D asset set v1
Documentation date: 2026-10-21

Files: base.png, eyes.png, mouths.png, brows.png.
Origin: Original character artwork created during development with the built-in image generation tool. These are prepared local assets, not images generated by an API at application runtime. No user API key is required to display this bundled set.

The design and generation references were used to create a consistent original character. Reference application screenshots were not copied into these PNG assets. This is not a claim that the artwork was drawn by hand, nor that every image model output will be identical or artifact-free.

Intended structure:
- base.png: 1024 x 1536 bust portrait base.
- eyes.png: six prepared states — open, quarter closed, half closed, three-quarter closed, closed, happy closed.
- mouths.png: twelve prepared states — closed, open small, open medium, open wide, smile closed, smile open, frown closed, frown open, funnel, pucker, press, side.
- brows.png: five used states — neutral, raised, lowered, worried, outer raised. An additional generated tile is not advertised as a separate supported action.

The renderer composites selected frames at configured fixed face rectangles. The ARKit52-named controls do not imply 52 separately painted motions; some combinations share approximate artwork. Gaze, cheek inflation and tongue extension have no matching artwork in this set.

prompts.txt contains concise recreation prompts, not a verbatim generation log. Exact crops, placement and rendering behavior are defined by the renderer configuration; rerunning the prompts alone does not reproduce compatible alignment automatically.

This asset set is separate from the bundled third-party pixiv VRM. Its existence does not change that model's source, license or attribution. See ../THIRD_PARTY_NOTICES.txt for the VRM. No Live2D or Inochi2D character assets/runtime were added for this set.
