VTuberProject 0.16.0 — OBS 浏览器源接入
2026-11-06，Asia/Seoul

用途
将独立角色画面放入同一台电脑上的 OBS 浏览器源。接收页固定为 1280×720，保留原画背景；它不是透明角色或虚拟摄像头。当前已提供接入页面与本机传输；浏览器已验证同步、输出尺寸、明确停止和演示录像，本轮没有验证实际 OBS 安装。

1. 在完整正式项目目录运行 npm start。
2. 打开 http://127.0.0.1:4173/short-hair-studio.html，等待角色载入。
3. 在工作台明确启用“直播画面”，点击打开独立画面确认连接。
4. 在 OBS 添加“浏览器”来源。关闭 Local file（本地文件），将工作台中显示的独立画面 URL 粘贴到 URL 字段。正式版默认是 http://127.0.0.1:4173/short-hair-output.html。
5. Width（宽度）设 1280，Height（高度）设 720；开启 Use custom frame rate（使用自定义帧率），FPS 可设 60。此数值是 OBS 的绘制请求，不保证识别、工作台或编码始终达到 60 fps。
6. 保持工作台标签页可见；可以将浏览器与 OBS 并排。不要切换到其他标签、隐藏或关闭工作台后期待摄像头／演示继续。接收页只接收角色状态，不需要相机或麦克风权限。

本轮验收副本使用端口 4177：工作台 http://127.0.0.1:4177/short-hair-studio.html；接收页 http://127.0.0.1:4177/short-hair-output.html。工作台和接收页必须连接同一个端口；不要让正式版工作台向验收版画面发送，或反过来。使用自定义 PORT 时，以该工作台显示的 URL 为准。127.0.0.1 只指本机，此方案没有提供另一台电脑的网络接收。

画面与停止行为
- 接收画面等比放入固定画布，切换脸部／全图或九方向不会改变输出尺寸。
- 手动静止也能保持输出，工作台每秒发送心跳。慢接收端只保留最新待处理状态，可能丢弃中途状态；该通道不是无损逐帧录像。
- 关闭“直播画面”会清空接收页角色，显示停止提示。关闭工作台会尝试停止；异常退出且服务未收到停止请求时，接收页可能仍保留最后一帧。连续 5 秒没有状态更新后，另一工作台可接管输出。
- 服务每秒发送状态心跳；工作台超过 5 秒没有新状态，或接收连接报错时，接收页保留最后画面并在右下角显示信号中断提示。收到新数据后提示消失。看到冻结角色不代表实时跟踪仍在进行。连接恢复后检查工作台输出状态，必要时重新启用。
- 开启“看原画”会按工作台状态输出中性原画。若需要保存完整录像，请使用工作台或 OBS 的录制功能，系数片段不能代替录像。
- OBS 默认的透明页面 CSS 无法抠掉 PNG 原画背景；本轮没有干净透明角色或透明视频管线。

没有画面时
确认 Node 服务仍在运行、工作台素材已加载、直播画面已启用、两个 URL 的端口一致。先在普通浏览器打开同一接收 URL，查看提示；连接失效后重新启用工作台输出，再刷新 OBS 浏览器源。摄像头权限只在工作台由用户主动开启时请求，不要在接收页尝试申请。

OBS 字段说明来源（2026-11-06 核对）：
https://obsproject.com/kb/browser-source
官方说明确认 URL、本地文件、视口尺寸和自定义 FPS 等字段；这里的尺寸和服务地址是本项目的设置建议，并不表示本轮已实际安装或验收 OBS。
